## Обзор

Этот Python-скрипт автоматизирует процесс отправки персонализированных писем с PDF-вложениями множеству получателей. Он считывает данные получателей из CSV-файла, проверяет адреса электронной почты и отправляет письма пакетами со случайными задержками, чтобы избежать блокировки как спам.

## Возможности

- **Парсинг CSV-данных**: Считывает информацию о получателях (email, имя, фамилия и связанные PDF-файлы) из CSV-файла
- **Валидация email**: Проверяет адреса электронной почты по разрешённым доменам (`edu.hse.ru`, `mail.ru`, `google.com`, `yandex.ru`)
- **Пакетная обработка**: Отправляет письма настраиваемыми пакетами для управления нагрузкой на сервер
- **PDF-вложения**: Автоматически прикрепляет указанные PDF-файлы из директории `pdf_files/`
- **Ограничение частоты**: Реализует случайные задержки между отдельными письмами (10-30 секунд) и между пакетами (5-15 минут)
- **Обработка ошибок**: Продолжает обработку даже при неудачной отправке отдельных писем с подробным логированием ошибок
- **TLS-шифрование**: Использует STARTTLS для безопасной передачи электронной почты

## Требования

- Python 3.6+
- Необходимые пакеты:
  - `python-dotenv`

Установка зависимостей:
```bash
pip install python-dotenv
```

## Конфигурация

Создайте файл `.env` в корне проекта со следующими переменными:

```env
SMTP_SERVER=smtp.yandex.ru
SMTP_PORT=587
MY_EMAIL=your_email@yandex.ru
PASSWORD=your_app_password
```

**Примечание**: Для Яндекс.Почты необходимо сгенерировать пароль приложения вместо использования обычного пароля. Включите «Пароли приложений» в настройках вашего аккаунта Яндекса.

## Формат CSV

Файл `addresses.csv` должен иметь следующий формат (без заголовка):

```csv
email,имя,отчество,pdf1,pdf2,...
```

**Пример:**
```csv
milleregor1@yandex.ru,Егор,Сергеевич,Брат_Брат.pdf,Брат_Брат.pdf
milleregor2@yandex.ru,Иван,Андреевич,Брат_Брат.pdf
milleregor3@yandex.ru,Денис,Альбертович,Брат_Брат.pdf
```

**Правила:**
- Каждая строка должна содержать минимум 4 поля (email, имя, фамилия и хотя бы один PDF)
- Адреса электронной почты должны соответствовать шаблону: `username@(edu.hse.ru|mail.ru|google.com|yandex.ru)`
- Имена PDF-файлов должны соответствовать реальным файлам в директории `files/`
- Используйте кодировку UTF-8 для CSV-файла

## Использование

1. Поместите все PDF-файлы в директорию `pdf_files/`
2. Подготовьте файл `addresses.csv` с данными получателей
3. Настройте файл `.env` с учётными данными SMTP
4. Запустите скрипт:

```bash
python main.py
```

## Как это работает

1. **Загрузка данных**: Скрипт считывает и проверяет все записи из `addresses.csv`
2. **Создание пакетов**: Получатели разделяются на пакеты по 100 человек (настраивается через `BATCH_SIZE`)
3. **Отправка писем**: Для каждого пакета:
   - Устанавливается SMTP-соединение с TLS
   - Отправляются персонализированные письма с PDF-вложениями
   - Между отдельными письмами делается пауза 10-30 секунд
   - После завершения пакета соединение закрывается
4. **Пауза между пакетами**: Делается пауза 5-15 минут между пакетами для избежания ограничения частоты

## Обработка ошибок

- **Некорректные строки CSV**: Пропускаются с предупреждением, показывающим номер строки
- **Неверный формат email**: Пропускается с предупреждением, показывающим неверный email
- **Отсутствующие PDF-файлы**: Вызовут исключение для конкретного письма (логируется, но не останавливает обработку)
- **Ошибки SMTP**: Логируются с деталями, обработка продолжается для остальных получателей

## Соображения безопасности

- Никогда не добавляйте файл `.env` в систему контроля версий
- Используйте специальные пароли приложений вместо основного пароля аккаунта
- Скрипт использует TLS-шифрование для передачи электронной почты
- Храните конфиденциальные учётные данные безопасно

## Настройка

- **Размер пакета**: Измените переменную `BATCH_SIZE` в функции `main()`
- **Диапазоны задержек**: Настройте значения `random.randint()` в функциях `send_batch()` и `main()`
- **Разрешённые домены**: Обновите регулярное выражение `email_pattern` в функции `read_csv()`
- **Шаблон письма**: Измените содержимое сообщения в функции `send_email()`

## Устранение неполадок

1. **Ошибка аутентификации**: Проверьте пароль приложения и настройки SMTP
2. **Таймаут соединения**: Проверьте подключение к интернету и статус SMTP-сервера
3. **PDF не найден**: Убедитесь, что файлы существуют в директории `pdf_files/` с точными именами
4. **Ошибки парсинга CSV**: Проверьте отсутствие пропущенных запятых или неправильную кодировку
